# Бэкенд WebLarek

Серверная часть проекта «Web-ларёк». Реализованы получение и создание товаров, оформление заказа, валидация данных, обработка ошибок и логирование.

## Технологии

- TypeScript
- Node.js и Express
- MongoDB и Mongoose
- Celebrate и Joi
- Winston и express-winston

## Запуск

Команды выполняются из папки backend.

Установить зависимости:

```bash
npm install
```

Создать файл .env на основе .env.example:

```bash
cp .env.example .env
```

Для локального запуска указать:

```env
PORT=3000
DB_ADDRESS=mongodb://127.0.0.1:27017/weblarek
```

Перед запуском сервера необходимо запустить MongoDB.

Запустить сервер:

```bash
npm run start
```

Запустить сервер с автоматическим перезапуском:

```bash
npm run dev
```

Собрать проект:

```bash
npm run build
```

Проверить код линтером:

```bash
npm run lint
```

## Загрузка товаров

Для импорта предоставленных товаров выполнить:

```bash
mongoimport --uri="mongodb://127.0.0.1:27017/weblarek" --collection=products --file=product.json --jsonArray
```

Для этой команды необходим установленный MongoDB Database Tools. Импорт выполняется один раз.

Изображения находятся в папке src/public/images и доступны по адресу /images/имя-файла.

## Маршруты

- GET /product — получить список товаров.
- POST /product — создать товар.
- POST /order — оформить заказ.

Ответ со списком товаров содержит поля items и total.

При оформлении заказа проверяются наличие товаров в базе, возможность их покупки и общая стоимость. Заказ не сохраняется в базе. В ответ возвращаются id и total.

## Обработка ошибок

- 400 — некорректные данные.
- 404 — маршрут не найден.
- 409 — товар с таким названием уже существует.
- 500 — внутренняя ошибка сервера.

## Логирование

Запросы и ответы записываются в request.log, ошибки — в error.log. Логи сохраняются в формате JSON и исключены из Git.
